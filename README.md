# Basic WebSocket Chat

A simple terminal-based WebSocket application built with Node.js and the `ws` package.

## What this project demonstrates
- Creating a WebSocket server
- Connecting multiple clients
- Sending messages from a client
- Receiving messages on the server
- Broadcasting messages to connected clients
- Handling connection and disconnection events

 ## Tech Stack
 - Node.js
 - WebSocket
 - ws
 - readline

## How to Run
### 1. Install dependencies
npm install
### 2. Start the server
node server.js
### 3. Start clients
Open two or more terminals and run:
``` bash
node client.js
```
Then type a message and press Enter.
